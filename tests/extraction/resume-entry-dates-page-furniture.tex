% Purpose (#221)
%   The two-page form of the entry-head reading-order assertion made by
%   resume-entry-dates-order.tex: with a running header and a `Page N of M'
%   folio on the page, a misordered dates/location column does not merely sort
%   after its own bullets, it sorts after the folio — landing an entry's dates
%   below the page furniture in every consumer that trusts the text layer.
%
%   Until #221 no fixture in tests/extraction/ rendered a second page at all,
%   so the interaction between an entry's right-hand column and page furniture
%   was untested here. It was `make tagging' that caught the #219 regression,
%   through tests/tagging/resume.expected.txt — the wrong way round for a defect
%   that reproduces identically on the untagged path this suite builds.
%
%   Assertion: on page 1 the dates and location must extract between the entry
%   heading and its bullets, and the folio must remain the last text on the
%   page. Lower `\CDossierRecordListEdgeAboveSkip' below 0.25 and the column
%   moves after `Page 1 of 2', and this baseline fails.
%
%   #219 closed without changing the component: Poppler decides this at page
%   level, so page 2's last entry still trails its own column and that is
%   expected output, not a pending fix. The assertion above is the whole
%   contract. docs/ATS-EXTRACTION.md#dates-and-right-alignment states the rule;
%   resume-entry-dates-order.tex carries the block-grouping measurement.
%
%   The committed baseline (resume-entry-dates-page-furniture.expected.txt) is
%   the assertion; regenerate it only for an intended, reviewed output change.
%
% Compile: lualatex -halt-on-error -interaction=nonstopmode resume-entry-dates-page-furniture.tex
% (run from the repository root, or with the root on TEXINPUTS as run.sh does)
%
%   The body is resume-entry-dates-page-furniture.inc, shared with
%   resume-entry-dates-default-medium.tex. `medium=print' is explicit because
%   the furniture is this fixture's subject and `screen' is the default (#327).
\documentclass[medium=print]{careerdossier-resume}
\input{resume-entry-dates-page-furniture.inc}
