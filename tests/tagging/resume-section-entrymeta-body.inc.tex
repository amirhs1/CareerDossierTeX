% resume-section-entrymeta-body.inc.tex — shared body for the per-section
% `entrymeta' tagging fixtures (#569).
%
% Deliberately one page, outside the five-document loop in run.sh, for the
% reason resume-entrymeta-inline-body.inc.tex gives: what is under test is the
% entry heading, and continuation furniture would only add noise.
%
% A `column' document (the default) whose Education section sets
% `entrymeta=inline' on \CDossierSection and whose Experience section, last on
% the page, is left at `column'. The join between an entry's cells differs
% between the two layouts -- \pdffakespace for `column', a marked-content
% artifact for `inline' -- so this is the one document in the suite where both
% joins meet in one structure tree. The claim `entrymeta' rests on is that it
% moves ink, not structure: the decoded structure text of an Education heading
% and of an Experience heading must take the same shape, `Title Dates', with a
% real U+0020 between the cells and no `|' in either.
%
% The `column' section is last on purpose. That is the order the manual
% recommends for extraction (#569): the last column entry on a page extracts
% its dates after everything below it under Poppler, and here that is only its
% own bullets.
