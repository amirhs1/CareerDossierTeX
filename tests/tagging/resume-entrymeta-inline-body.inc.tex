% resume-entrymeta-inline-body.inc.tex — shared body for the `entrymeta=inline'
% tagging fixtures (issue #230).
%
% Deliberately one page. This fixture sits outside the five-document loop in
% run.sh, which asserts two-page continuation furniture; what is under test here
% is the entry heading, and page furniture would only add noise to the decoded
% structure text.
%
% The first entry carries all four fields, so both heading lines join. The
% remaining three are the optional-field shapes that can put a separator next to
% an absent cell: no dates, a location with no organization, and an organization
% with no location. A stray `|' in any of them is visible in the Poppler
% baseline, and a `|' that reached the *structure tree* in any of them is
% visible in the structure baseline.
