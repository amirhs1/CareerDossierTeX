% resume-section-need.tex — issue #333: a section heading arriving with too
% little room to introduce anything.
%
% The bound that replaced the penalty after the section rule
% (\CDossierSectionNeedLines) only does something at one moment: when a section
% heading reaches the page with fewer than that many lines left. No other fixture
% reaches that moment — the filler in the rest of the suite is bullet lists,
% which break internally, so a heading never arrives at the page edge. This one
% fills the page in two-line steps with bodiless entries instead, so the
% "Education" heading lands exactly there.
%
% The entry count is not arbitrary. At nineteen filler entries and
% \CDossierSectionNeedLines = 0, "Education" is the last line on page one — a
% stranded section heading, the thing issue #145 forbids and the failure this
% bound exists to prevent. At the committed value of 4 the heading moves to page
% two instead. That two-sided behaviour is what makes this fixture an assertion
% rather than a rendering: the runner's "no page ends with a section heading"
% check passes here for a reason, and would fail if the bound stopped working.
%
% Re-derive the count if the filler, the fontsize, or the margin changes; the
% figure is a property of this exact content.
