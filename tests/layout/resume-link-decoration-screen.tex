% resume-link-decoration-screen.tex — line breaking with `medium=screen' link
% decoration (issue #278).
%
% The decoration is a rule drawn under author-written anchor text, and the
% failure it has to be checked against is a line-breaking one. ulem, the obvious
% vehicle, reboxes what it underlines and breaks the result at its spaces only:
% an underlined run either loses its interior break points or becomes one
% unbreakable box. lua-ul attaches an attribute and leaves the node list alone,
% so TeX breaks a decorated paragraph exactly as it breaks an undecorated one.
%
% This fixture states that as a rendered assertion. The first bullet's anchor
% text is long enough to wrap mid-phrase at this size and margin, and the prose
% paragraph's anchor sits at the end of a line; the runner's "no overfull boxes"
% check is what fails if the decoration ever starts constraining the break.
%
% The address links are here for the other half of the split: `\CDossierLink'
% and the contact line render the address as its own visible text, and issue
% #278 settled deliberately that those stay undecorated. Underlining them would
% throw away the intra-URL break points of issues #294 and #308, and the
% overfull check would report it here.
