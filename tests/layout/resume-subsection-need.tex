% resume-subsection-need.tex — issue #337: a subsection heading arriving with
% too little room to introduce anything.
%
% \CDossierSubsectionNeedLines is the second heading level's half of the bound
% issue #333 introduced, and like that bound it does something at exactly one
% moment: when a subsection heading reaches the page with fewer than that many
% lines left. resume-section-need.tex reaches that moment for a section; nothing
% reached it for a subsection, and the two are separate code paths with separate
% counts (4 lines against 3, because a subsection has no rule and the entry
% heading under it carries its own keep down to its first body line).
%
% The filler is bodiless entries in two-line steps, as in resume-section-need.tex
% and for the same reason: bullet lists break internally, so a heading filled up
% to with them never arrives at the page edge at all.
%
% The entry count is not arbitrary. At this count and
% \CDossierSubsectionNeedLines = 0, "Academic" is the last line on page one — a
% stranded heading, the thing issue #145 forbids and this bound exists to
% prevent. At the committed value of 3 it moves to page two with its entry.
% The runner's "no page ends with a section heading" check reads
% \CDossierSubsection titles too, so that two-sided behaviour is what makes this
% an assertion rather than a rendering.
%
% Re-derive the count if the filler, the fontsize, or the margin changes; the
% figure is a property of this exact content.
