% ats-user-template-doc.tex — issue #450. The minimal user template, kept
% compilable. This file is the template: it was published as prose in
% docs/ATS-EXTRACTION.md until that document was reduced to design rules, and a
% copy in a document nobody compiles is what #185 and #450 exist to prevent.
% The manual's "Complete examples" chapter and examples/ carry the same shape at
% greater length, and smoke_doc_drift guards the manual's copy separately.
%
% Keep the names fictional but plausible. Obvious placeholders such as `First
% Last' or `Company 1' can themselves be skipped by parsers, as Greenhouse's
% documentation notes. tests/smoke/run.sh compares the two texts before compiling
% this one, so they cannot drift apart.
%
% #185 is why: an uncompiled example in a document nobody re-reads goes stale
% silently, and a reader cannot tell which of several published templates is
% current. The template compiled at the time this fixture was written, so this
% is a guard against a future rename rather than a repair of a present break.
%
% What it exercises that no other fixture does: the documented \hypersetup
% override of the derived PDF metadata sitting in a preamble beside
% \CDossierSetup, and the profile's phone and website keys in one document with
% an entry and a bullet list.
\documentclass[fontsize=11pt]{careerdossier-resume}

% Optional. pdftitle, pdfauthor, and pdflang are derived from the profile
% automatically; set them only to override the derived values. A \hypersetup
% anywhere in the preamble wins, before or after \CDossierSetup.

  pdftitle  = {Resume — Zoë Dvořák},
  pdfauthor = {Zoë Dvořák}
}
