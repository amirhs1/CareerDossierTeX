% \CDossierLink extends url.sty's \UrlBreaks with the letters and digits, so a
% long address may break anywhere rather than only after punctuation. That is
% what keeps the bullet below off the margin, and it is exactly the kind of
% break this suite exists to judge: url.sty inserts a penalty and no
% discretionary hyphen, so the wrapped address must still concatenate back to
% the original character for character. Bare text would instead *hyphenate* the
% address and paste back with an inserted hyphen, which no `pdftotext' word
% check would notice.
%

% so the VERIFIED lines must report a wrap; a run reporting none has stopped
% exercising the property.

% The third token is a real, publicly resolvable address — a Wikipedia
% advanced-search result, 262 characters, with the query string an ordinary
% search produces. It is what proves the escaping round-trips: the source writes

% verbatim argument, and the token below is the unescaped form the page must
% show and the reader must be able to paste. A source that escaped wrongly would
% render `\%3A' or drop the parameters and be reported MISSING here.
